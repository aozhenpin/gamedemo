# 寂静病房 · SILENT WARD

双人恐怖躲猫猫。两人各自在一张废弃医院地图上躲藏，双方确认后**交换病房**——你进入对方的地图寻找对方留下的隐藏体，同时对方也在你的地图上找你。每张地图都有一只鬼，平时用灯光闪烁、耳语、开门声制造压迫，周期性进入**猎杀**状态追击。

纯浏览器运行，无任何外部美术/音频资源：所有贴图、几何、音效、界面均由代码程序化生成。

## 地图设计

地图按恐怖游戏的三条核心原则生成（参考《Alien: Isolation》与《Resident Evil》系列的关卡分析）：

- **视线管理（information asymmetry）**：走廊被柱列、顶部横梁、折叠屏风切碎，没有一眼望到底的长直道；每个房间都有暗角和遮挡，威胁总在视线外。
- **环路（loops）**：外环走廊 + 十字走廊 + 中央护士站，四个街区各切 3 列 × 2 行；每间房 1~3 个门，角房常有两个出口。追逐时鬼可以绕后，玩家也能绕柱甩开。
- **地标与节奏**：中央护士站（暖光、值班台、白板）是唯一的安全地标；四个街区分别对应病房（绿）、手术区（冷蓝）、停尸区（深蓝）、办公区（暖黄），靠地面色与环境光区分方位。

单张图为 38×30 格（约 84×66 米）、24 间房、31~33 个门、30+ 个藏身点、约 500 个家具碰撞体，门洞与出生点自动避开家具。四个街区各切 **3 列 × 2 行**，房间约 7~9 米见方，避免出现十几米宽的空旷大厅。

**建筑细节层**：沿所有地面/墙边界生成踢脚线，走廊墙加防撞扶手与柱列、顶部横梁与管线；每道门配双开门扇（半开）、门槛、门框、门楣与房间标识；房间内有吊顶通风口、墙面医疗气体面板、病历夹、免洗消毒液、手套盒、开关、挂钟、公告板、灭火器。六类房间各自成套布景（病床+床头柜+监护仪+输液架+床上桌+隔帘、手术台+麻醉机+器械台+刷手池+壁柜、遗体冷藏抽屉+不锈钢台+吊秤+标本架、货架+储物柜+清洁车、办公桌+文件柜+书架+沙发、隔间+洗手台+镜+淋浴），空地率大幅下降。

俯视图自检：

```bash
node tools/map.mjs 20261112   # 输出 shots/map-<seed>.png，并统计连通性
node tools/rooms.mjs 20261112 # 逐间房取景到 shots/room-*.png，人工核对摆位
```

## 运行

```bash
npm install
npm start
```

浏览器打开终端打印的地址（默认 `http://localhost:3000`），两人输入**同一个 4 位房间码**即可同房。

> 建议用**两个独立窗口**（或两台设备）并排玩。浏览器会暂停后台标签页的 `requestAnimationFrame`，放在同一个窗口的两个标签页里，切走的那一方会卡住。

## 操作

| 按键 | 作用 |
| --- | --- |
| `WASD` | 移动 |
| `Tab` | 开启 / 关闭冲刺（移动时消耗体力，脚步声会引来鬼） |
| `Space` | 跳跃（可跳上马桶等低矮物体） |
| `Shift` | 蹲下 / 站起（蹲下时更安静） |
| `E` | 躲进柜子/帘后 · 离开 · 检查藏身处 |
| `F` | 手电（会暴露自己） |
| 右键 | 举起 EMF 探测器（越靠近对方读数越高、蜂鸣越密） |
| `R` | 躲藏阶段确认位置 |
| `G` | 切换画质（low / mid / high） |

## 玩法

1. **躲藏**：两人各自在自己的医院里找位置。确认时不能离入口 7 米以内。
2. **交换**：双方都确认后白屏转场，各自进入对方的地图（从另一端入口进入）。
3. **寻找**：用 EMF 定位对方的隐藏体。对方若躲在柜子里，需要走到对应柜子前按 `E` 检查。
4. **鬼**：活动度攒满后会开始猎杀，未发现你时速度 5.5 m/s，发现并贴身时 6.05 m/s（略高于冲刺 5.85）。躲进柜子、断开视线、保持安静可以让它失去目标并退开。
5. **胜负**：先找到对方的人获胜；被鬼抓住则直接失败。4 分钟倒计时，超时为平局。

## 技术栈

- **渲染**：Three.js r169 / WebGL2，ACES 色调映射、PCF 软阴影、MSAA 半浮点渲染目标
- **后期**：Bloom、自定义调色（色差 / 暗角 / 桶形畸变 / 胶片颗粒 / 恐惧压暗 / 受击红闪）、可选 SSAO（high 档）
- **材质**：Canvas 程序化生成 albedo / 法线 / 粗糙度（瓷砖、剥落墙面、金属锈蚀、织物、血迹、帘布）
- **场景**：种子化楼层生成（走廊 + 十字走廊 + 病房 / 手术室 / 储藏间 / 值班室 / 停尸间 / 盥洗室），静态几何按材质合并，导航网格 A*
- **音频**：WebAudio 全合成（低频嗡鸣、心跳、脚步、耳语、门轴、猎杀 stinger、EMF 蜂鸣）
- **鬼**：程序化生成的 3D 怪异人形——皮肤贴图带静脉/瘀斑/污垢，`MeshPhysicalMaterial` 的清漆层做湿滑高光；外露肋骨与脊椎、过长手臂与五爪、过长的脖颈、整个脱臼般张开的下颌与尖牙、嘴里的血、湿黏长发、撕裂下摆的破布长袍；红眼与幽光点光源；待机时抽搐、猎杀时前扑。
- **联机**：Node.js `http` + `ws` 房间服务器；地图由种子在两端确定性生成，只同步事件，不传几何与位置

## 开发

单机预览（跳过联机，直接进入寻找阶段，带隐藏体与鬼）：

```
http://localhost:3000/?dev=1
http://localhost:3000/?dev=1&cam=corridor   # 走廊
http://localhost:3000/?dev=1&cam=ward       # 病房
http://localhost:3000/?dev=1&cam=or         # 手术室
http://localhost:3000/?dev=1&cam=hub        # 中央护士站
http://localhost:3000/?dev=1&cam=ghost      # 鬼
```

截图自检（自动起服务器、无头渲染到 `shots/`）：

```bash
node tools/shot.mjs --scene=corridor,ward,or,ghost
```

自动化验证：

```bash
node tools/smoke.mjs   # 房间协议
node tools/flow.mjs    # 双人完整流程（需要服务器已在运行）
```
